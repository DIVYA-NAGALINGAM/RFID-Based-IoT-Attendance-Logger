RFID-Based IoT Attendance Logger

Project Overview

An RFID-based attendance logging system developed using ESP32 and RC522 RFID reader. It identifies RFID cards using their unique identification numbers (UID) and displays attendance information.

Components Used

- ESP32 Development Board
- RC522 RFID Reader
- RFID Cards / Tags
- Jumper Wires

Technologies Used

- Embedded C / Arduino Programming
- ESP32
- SPI Communication
- Wokwi Simulator

Working Principle

1. RFID reader detects the RFID card.
2. ESP32 reads the card's unique UID.
3. The UID is displayed in the Serial Monitor.
4. Attendance status is displayed.

Applications

- Student Attendance Management
- Access Control Systems
- Smart Identification Systems

Simulation

Designed and tested using Wokwi Simulator.
